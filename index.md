# Kephaleos — Index

The real entry points are the dashboards:

- **[Home](./00-dashboard/home.md)** — navigation
- **[Knowledge map](./00-dashboard/knowledge-map.md)** — what Kephaleos knows
- **[Today](./00-dashboard/today.md)** — what deserves attention now

Everything else is one folder away:

- `wiki/` — canonical knowledge (concepts, technologies, projects,
  organizations, people, decisions, solutions, runbooks, learnings,
  research, synthesis)
- `raw/` — evidence (inbox, notes, meetings, articles, documents,
  conversations, ideas, assets)
- `work/` — active in-flight context (projects, architecture, incidents)
- `personal/` — personal knowledge (goals, learning, finance, journal)
- `templates/` — page skeletons
- `CLAUDE.md` — Kephaleos Knowledge Maintainer charter (Phase 1.1)
- `README.md` — human orientation
- `log.md` — meaningful maintenance events (not per-call telemetry)
