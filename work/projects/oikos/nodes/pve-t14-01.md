# pve-t14-01

Bootstrap Proxmox node — the ThinkPad T14 that starts everything.

## Status

- **Hardware**: DEPLOYED (owned, on hand)
- **OS/hypervisor**: **IN PROGRESS** — Proxmox VE install started 2026-09-18
- **In production use**: NO
- **FQDN**: `pve-t14-01.oikos.home.arpa` — per [[../../../../wiki/decisions/oikos-0001-dns-namespace|ADR oikos-0001]]. If the install temporarily used `homelab.arpa`, apply the `hostnamectl` + `/etc/hosts` fix from the ADR before finishing Phase 0.

## Hardware

- **Model**: Lenovo ThinkPad T14 Gen 2
- **CPU**: 4 cores / 8 threads
- **RAM**: 40 GB
- **Storage**: 512 GB SSD (single)
- **NIC**: onboard Ethernet + Wi-Fi (**Wi-Fi is NOT used for hypervisor traffic**)

## Network (planned)

- **Hostname**: `pve-t14-01.oikos.home.arpa`
- **Mgmt IP**: `172.27.10.11/24`
- **Gateway**: `172.27.10.1`
- **DNS**: TBD (Phase 4 installs internal DNS)

**NOTE**: this IP is not yet reachable — the management VLAN doesn't exist until Phase 3. During Phase 0 the node lives on whatever the household network provides today (DHCP off the ISP router). The IP transition happens as part of Phase 3.

## Role over time

| Phase | Role |
|---|---|
| 0 | Bootstrap Proxmox host, first VMs |
| 1 | *Possibly* host OPNsense as a VM if no dedicated firewall appliance yet — treat as a risky interim state (single point of failure for household Internet) |
| 3 | Host internal DNS/DHCP as VMs |
| 5 | Host observability stack (Prometheus/Grafana) as VMs |
| 6 | Host EVE-NG for advanced CCNA labs |
| 8+ | Demote to secondary compute once `pve-01` exists |
